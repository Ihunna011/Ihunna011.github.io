UNIVERSITY COURSEWORK / PYTHON

Dijkstra Route Finder

A route-finding program that accepts a start and destination, searches a weighted graph and returns a path with its total cost.

PythonDijkstraWeighted graphs

What it demonstrates

Representing locations and connections as a graph, applying shortest-path reasoning and presenting the result clearly.

Algorithm choice

Dijkstra finds shortest paths when edge weights are non-negative. The result depends on the connections and costs supplied to the graph.
