# Ihunna Nwankwo — Portfolio

A static, responsive portfolio for GitHub Pages. No installation or build step is required.

## Preview on your computer

Extract the ZIP and open `index.html` in your browser. Keep the `assets` folder, `style.css` and `script.js` alongside it.

## Publish to GitHub Pages

1. Sign in to https://github.com/Ihunna011.
2. Create a public repository called `Ihunna011.github.io`. If it already exists, back up its contents before replacing anything.
3. Upload the contents of this folder to the repository root. `index.html` must be at the top level, not inside another `portfolio` folder. Include the complete `assets` folder.
4. Commit the upload to `main`.
5. Open the repository's **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose **main** and **/(root)**, then **Save**.
8. Check Pages for deployment progress and the published link. Your expected address is https://ihunna011.github.io/.

Official instructions: https://docs.github.com/en/pages/quickstart

## Edit your portfolio

- `index.html`: headings, descriptions, project links, experience and email.
- `style.css`: colours, typography, spacing and responsive layouts.
- `script.js`: mobile navigation and screenshot viewer.
- `assets/Ihunna_Nwankwo_CV.pdf`: replace with an updated CV using the same name.
- `assets/`: supplied screenshots and favicon.

The current PDF is the CV you supplied, unchanged. Its Lumina description predates the screenshots. Update the PDF separately when ready.

Lumina is presented as an ongoing, AI-assisted personal project with a private repository. No private source code is included. Screenshots document the supplied prototype, rather than a public live application.

The site works without JavaScript: navigation remains visible and screenshot links open the full images. With JavaScript, mobile navigation collapses, screenshots open in a keyboard-accessible modal, and offscreen sections fade into view. Reduced-motion preferences disable the animations. Buttons and links include hover and keyboard-focus feedback.

## Design

Editorial black-and-white layout with red accents, a personal introduction, thin rules and lighter project sections. Scroll fades, hover feedback and mobile navigation are preserved.
